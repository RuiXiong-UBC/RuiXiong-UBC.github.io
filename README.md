# 个人主页 · 使用说明

一个中英双语个人主页，iOS 风格的文字与配色（白色为主，浅灰与 UBC 深蓝为辅）。第 0 层是一张固定的背景照片，
第 1 层的「关于我」和「简历」从照片上滑过；简历分成四个独立页面：
教育背景、实习与工作经历、出版物、项目。

## 文件

| 文件 | 作用 | 需要改吗 |
|---|---|---|
| `content.js` | **网站上所有文字、图片路径、链接** | 要改的就是它 |
| `images/` | 照片、校徽、公司标志 | 放你自己的图片 |
| `index.html` 等 5 个页面 | 页面外壳 | 不用改 |
| `assets/` | 样式和脚本 | 不用改 |

## 两种视角

- **访客**：打开网站看到的是固定内容，不能编辑。
- **你（管理员）**：在网址后面加 `#admin`，例如 `https://yourname.github.io/#admin`。
  进入后每个模块右上角都有「编辑」按钮，条目可以上移、下移、删除，也可以新增条目和分组。
  底部管理栏里可以改网站信息（名字、背景照片、默认语言）和联系方式。
  这台电脑的浏览器会记住管理模式，点「退出管理」恢复成访客视角。

每段文字都有 中 / EN 两个输入框。只填中文时，英文页面也显示中文。
每段经历都可以加段落、要点、图片、按钮链接，右侧可以放校徽或公司标志。
段落里按回车换行，网页上也会换行。
教育背景的每一段还有「课程列表」：每行一门课，成绩写在 `|` 后面，例如 `AP 微积分 BC | 5/5`。
想按年级分栏，就单独写一行 `# 大一`、`# 大二`，下面跟着这一年的课。

## 第一次上线（GitHub Pages）

1. 在 GitHub 新建仓库，名字叫 `你的用户名.github.io`
2. 把这个文件夹里的所有文件上传到仓库根目录
3. 仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支选 `main`，文件夹选 `/ (root)`
4. 一两分钟后打开 `https://你的用户名.github.io` 就能看到

## 在网页上保存修改

管理模式里改的内容会先存在你自己的浏览器里（访客看不到）。
点「保存到网站」才会真正更新网站：

1. 第一次保存时会弹出「GitHub 设置」，按里面的步骤生成一个 **Fine-grained token**：
   只选网站这一个仓库，权限 `Contents` 选 `Read and write`
2. 填好用户名、仓库名和令牌，点「保存设置」
3. 之后每次点「保存到网站」，修改和上传的图片会直接提交到仓库，约 1 分钟后所有人都能看到

令牌只存在你这台电脑的浏览器里。访客即使打开 `#admin`，也只能改到自己电脑上的预览，
没有令牌就无法改动真正的网站。不要把令牌发给别人，也不要写进任何文件。

不想用令牌也可以：在管理模式里改完，点「下载 content.js」，用它替换仓库里的同名文件。
（这种方式下，网页上传的图片会直接嵌在 content.js 里，文件会变大；
更推荐把图片放进 `images/` 文件夹，再在编辑框里填路径，例如 `images/me.jpg`。）

## 直接改 content.js

也可以用任何文本编辑器（推荐 VS Code）打开 `content.js` 修改，文件开头有格式说明：

- 双语写法：`{ zh: "中文", en: "English" }`；两种语言一样就直接写 `"文字"`
- 文字里可以写 HTML：`<a href='https://…'>链接</a>`、`<b>加粗</b>`
- 新增一段经历：复制一整段 `{ … },`，粘贴后修改
- 不需要的字段整行删掉即可

改完在浏览器里刷新就能看到效果（直接双击 `index.html` 打开也可以预览）。

## 小提示

- 背景照片建议横向、宽 2000 像素左右、文件小于 1 MB
- 校徽和公司标志用透明背景的 PNG 或 SVG 最好看
- 访客的语言选择会被记住；也可以分享英文版链接：`index.html?lang=en`
- 文字用的是系统字体：苹果设备上就是 iOS 的 SF 字体和苹方，Windows 上会用系统自带的相近字体
